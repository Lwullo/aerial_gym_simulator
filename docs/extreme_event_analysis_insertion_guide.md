# 论文极端事件分析加入指南

本文档说明如何在论文中加入“极端事件分析”，包括应该加在哪里、添加哪些指标、使用哪些数据、正文怎么写。

适用论文文件：

`/home/lwulo/下载/论文讲故事版.docx`

主要数据来源：

- `docs/experiment_results_analysis_result_with_saved_traces.md`
- `aerial_gym/rl_training/rl_games/runs/result_exp4_multiH_multiW_noObs/combined_analysis_stats/combined_key_metrics.csv`
- `aerial_gym/rl_training/rl_games/runs/result_exp4_multiH_multiW_noObs/combined_analysis_stats/combined_attitude_tail_metrics.csv`
- `aerial_gym/rl_training/rl_games/runs/result_exp4_multiH_multiW_noObs/combined_analysis_stats/combined_per_condition_metrics.csv`

## 1. 为什么要加入极端事件分析

目前论文主要使用：

- 平均落点误差
- 中位落点误差
- R@2m / R@3m
- Roll / Pitch 平均值
- Impact 平均值

这些指标只能说明“平均或多数样本”的表现，不能回答以下问题：

1. 是否存在少数投放误差非常大的失败样本？
2. 姿态稳定性差是整体都差，还是少数极端姿态拉高了均值？
3. 强风或复杂场景下，算法是否出现长尾风险？
4. MPC 虽然姿态稳定，但是否因为大量不投放而回避了危险样本？
5. Proposed 是否真的降低了极端落点偏差，而不只是降低平均误差？

因此需要加入极端事件指标，补充说明尾部风险。

## 2. 建议加入的位置

建议在论文第五章“仿真结果”中加入三处。

### 2.1 第一处：在实验设置后新增“评价指标”小节

建议位置：

```text
第五章 仿真结果
5.1 实验设置
5.2 评价指标
5.3 实验一：固定高度、固定风速、无障碍
...
```

如果你现在没有“评价指标”小节，就新增：

```text
5.2 评价指标与极端事件定义
```

这里负责定义：

- dropped-only 指标
- overall 指标
- 落点误差尾部指标
- 姿态极端事件指标
- 冲击尾部指标

### 2.2 第二处：在每个实验分析段后加“极端事件分析”

建议每个实验结构改成：

```text
实验一：固定高度、固定风速、无障碍
图5-x 投放精度CDF图
图5-x 投放冲击CDF图
图5-x 投放时母机姿态数据图
表5-x 投放精度数据汇总
表5-x 姿态与冲击数据汇总
平均性能分析
极端事件分析
```

每个实验不一定都放一张极端事件表，正文写2-4句话即可。

重点实验建议详细写：

| 实验 | 是否详细写极端事件 | 原因 |
|---|---|---|
| 实验一 | 简短写 | 简单场景，用于说明基础尾部表现 |
| 实验二 | 简短写 | 说明障碍物没有明显破坏 Proposed 精度尾部 |
| 实验三或多高度实验 | 重点写 | 随机高度是 PPO 失效的主要原因 |
| 多风速实验 | 重点写 | 最能说明风速增强导致尾部误差扩大 |
| 综合复杂场景 | 重点写 | 最能支撑论文最终结论 |

### 2.3 第三处：在所有实验后新增“综合极端事件风险分析”

建议位置：

```text
5.x 综合性能对比
5.x.1 投放精度综合分析
5.x.2 姿态稳定性与冲击综合分析
5.x.3 极端事件风险分析
```

这一节放总表，集中说明四种算法的尾部风险。

## 3. 需要添加的指标

### 3.1 投放精度极端事件指标

| 指标 | 含义 | 论文解释 |
|---|---|---|
| `P90` | 已投放样本中90%分位落点误差 | 表示90%的投放误差不超过该值 |
| `P95` | 已投放样本中95%分位落点误差 | 更关注极端大误差 |
| `P99` | 已投放样本中99%分位落点误差 | 反映最极端偏差 |
| `CVaR90` | 误差最大的10%样本的平均误差 | 衡量长尾风险强度 |
| `Overall@3m` | 全部case中落点误差小于3m的比例，未投放视为失败 | 衡量完整任务成功率 |

你当前 `combined_key_metrics.csv` 已经有：

- `mean`
- `median`
- `p90`
- `r2`
- `r3`
- `overall_r2`
- `overall_r3`

如果论文时间有限，投放精度极端指标可以先使用：

```text
P90 + Overall@3m
```

如果要更完整，再额外统计：

```text
P95 + P99 + CVaR90
```

### 3.2 姿态极端事件指标

定义合成释放姿态角：

```text
theta_drop = sqrt(roll_drop^2 + pitch_drop^2)
```

建议加入以下指标：

| 指标 | 含义 | 推荐程度 |
|---|---|---|
| `theta median` | 释放姿态角中位数 | 推荐 |
| `theta P90` | 90%分位释放姿态角 | 必须 |
| `theta P95` | 95%分位释放姿态角 | 必须 |
| `theta P99` | 99%分位释放姿态角 | 可选 |
| `CVaR90 theta` | 姿态角最大的10%样本平均值 | 推荐 |
| `theta > 30deg` | 极端姿态事件比例 | 必须 |

为什么建议用 `theta > 30deg`：

- `theta > 20deg` 在你当前学习方法中比例较高，更像“中等姿态风险”
- `theta > 30deg` 更适合作为“极端姿态事件”
- `theta = sqrt(roll^2 + pitch^2)` 比单独看 Roll/Pitch 更适合衡量释放姿态综合偏差

### 3.3 冲击极端事件指标

当前冲击指标定义：

```text
impact = alpha * delta_v + beta * delta_omega
```

当前代码参数：

```text
alpha = 1.0
beta = 0.8
```

建议加入：

| 指标 | 含义 |
|---|---|
| `Impact Mean` | 平均释放冲击 |
| `Impact P90` | 90%分位释放冲击 |
| `Impact P95` | 95%分位释放冲击 |

当前 `combined_key_metrics.csv` 已经有 `impact_p90`，可以先用 `Impact P90`。

## 4. 可直接加入论文的指标定义文字

建议放在“评价指标与极端事件定义”小节。

可直接粘贴：

```text
除平均值和中位数外，本文进一步引入极端事件指标，以分析不同方法在少数高风险样本中的表现。对于投放精度，本文统计落点误差的P90分位值，用于衡量尾部大误差风险；同时引入Overall@3m指标，将未投放样本视为任务失败，以反映完整任务层面的有效命中率。对于释放姿态，定义合成姿态角 theta_drop = sqrt(roll_drop^2 + pitch_drop^2)，并统计其P90、P95、CVaR90以及theta_drop > 30deg的比例。其中，CVaR90表示姿态角最大的10%样本的平均值，用于描述极端姿态事件的强度。对于释放冲击，除平均冲击外，进一步统计Impact P90，以评估少数高冲击释放样本对系统稳定性的影响。
```

## 5. 建议添加的总表

建议在“综合极端事件风险分析”中加入两张表。

### 5.1 表A：综合投放精度尾部风险

数据来源：

`combined_key_metrics.csv`

建议表名：

```text
表5-x 综合投放精度尾部风险指标
```

建议表格：

| Method | Drop Rate | Mean Error | Median | P90 | R@3m | Overall@3m |
|---|---:|---:|---:|---:|---:|---:|
| PPO | 98.99% | 8.061 m | 2.748 m | 20.470 m | 51.02% | 50.51% |
| Proposed | 97.04% | 2.669 m | 1.034 m | 7.669 m | 82.97% | 80.51% |
| PPO-GRU | 97.32% | 3.275 m | 1.286 m | 11.108 m | 76.95% | 74.89% |
| MPC | 52.69% | 5.101 m | 2.705 m | 15.004 m | 62.88% | 33.13% |

分析重点：

- Proposed 的 `P90=7.669m`，低于 PPO 和 PPO-GRU
- Proposed 的 `Overall@3m=80.51%`，最高
- MPC 的 dropped-only `R@3m=62.88%` 不低，但 `Overall@3m=33.13%` 低，原因是投放率只有 `52.69%`

可直接粘贴的分析段：

```text
从综合投放精度尾部风险看，Proposed 的P90误差为7.669 m，明显低于PPO的20.470 m和PPO-GRU的11.108 m，说明本文方法不仅降低了平均误差，也有效抑制了少数大偏差样本。PPO虽然投放率较高，但P90误差显著增大，表明其在复杂条件下存在明显长尾偏差。MPC在已投放样本中的R@3m为62.88%，但由于Drop Rate仅为52.69%，其Overall@3m下降至33.13%，说明MPC通过保守释放策略规避了大量困难样本，整体任务成功能力受限。
```

分析重点：

- MPC 姿态尾部最小


## 6. 每个实验后怎么写极端事件分析

### 6.1 实验一：固定高度、固定风速、无障碍

写作目的：

说明简单环境下 Proposed 的尾部误差优于 PPO-GRU，但姿态不是最优。

可直接粘贴：

```text
从极端事件角度看，实验一中Proposed的P90落点误差低于PPO和PPO-GRU，说明其在简单场景下能够减少少数大偏差投放样本。MPC的释放姿态和冲击尾部最小，但其投放率明显低于学习方法，因此不能仅依据已投放样本评价其整体任务性能。该结果表明，在基础环境中，Proposed的优势主要体现在落点误差尾部控制，而不是绝对释放姿态最小。
```

### 6.2 实验二：固定高度、固定风速、随机障碍

写作目的：

说明障碍物没有破坏 Proposed 的尾部精度，但姿态仍存在权衡。

可直接粘贴：

```text
在随机障碍条件下，Proposed仍保持较低的P90误差，说明其投放决策未因障碍扰动出现明显长尾退化。PPO-GRU虽然在部分姿态和冲击指标上接近或略优于Proposed，但其P90落点误差更大，表明仅依赖循环记忆仍难以稳定抑制极端落点偏差。MPC在姿态尾部方面最稳定，但由于未投放样本较多，其Overall@3m仍显著低于学习方法。
```

### 6.3 随机高度实验

写作目的：

说明 PPO 的问题不是少数异常值，而是随机高度下整体失效。

可直接粘贴：

```text
随机高度条件下，PPO的平均误差和中位误差同时显著增大，说明其性能退化并非仅由少数极端样本造成，而是多数样本均出现释放时机偏差。相比之下，Proposed和PPO-GRU均能维持较低误差，表明时序建模对于高度变化下的投放决策是必要的。其中Proposed的P90误差低于PPO-GRU，说明MLP前端与GRU结合后能够进一步降低高度变化引起的尾部偏差风险。
```

### 6.4 多高度、多风速、无障碍实验

写作目的：

说明风速越高，尾部风险越大；Proposed 对精度尾部控制最好，但高风速下姿态风险上升。

可直接粘贴：

```text
多风速实验表明，随着主风速度等级由低到高增加，各方法的落点误差尾部均出现扩大。Proposed在低、中、高风速下均保持学习方法中最低的P90误差，说明其对风速变化具有更好的尾部风险抑制能力。PPO在不同风速下均存在较高误差，表明其主要失效因素来自随机高度与风扰耦合下的释放时机泛化不足。需要注意的是，高风速下Proposed和PPO-GRU的释放姿态尾部风险明显增大，说明循环策略在强扰动条件下可能以更激进的释放姿态换取落点精度。
```

### 6.5 综合复杂场景实验

写作目的：

最终证明 Proposed 综合最优，但承认姿态不是最优。

可直接粘贴：

```text
综合复杂场景中，Proposed在平均误差、P90误差和Overall@3m上均优于PPO和PPO-GRU，说明其在多高度、多风速和障碍物耦合条件下具有更好的投放精度和尾部误差控制能力。PPO-GRU与Proposed接近，但P90误差仍更大，表明仅使用GRU难以完全替代MLP对当前状态的瞬时特征提取。MPC在释放姿态和冲击尾部上仍最稳定，但其投放率较低，导致整体任务成功率不足。该结果说明，Proposed的主要优势是提升复杂场景下的整体命中率并降低落点误差长尾，而不是取得最小的释放姿态角。
```

## 7. 如何解释“姿态数据不好”

你的结果中，学习方法的姿态角确实不如 MPC。不要回避这个问题。

建议解释为：

```text
学习方法为了提高投放率和落点精度，会在部分复杂状态下选择更激进的释放时机，因此释放姿态角和冲击指标高于MPC。MPC则倾向于在姿态更稳定时释放，因此姿态尾部最小，但代价是大量case未投放或撞毁未投放，整体命中率降低。
```

不要写：

```text
本文方法在姿态稳定性上全面优于其他方法。
```

应写：

```text
本文方法在精度、投放率和尾部误差控制方面具有综合优势，但在极端姿态稳定性方面仍存在改进空间。
```

## 8. 如何解释 Proposed 和 PPO-GRU 的差异

建议围绕“精度尾部”解释，不要只看均值。

可写：

```text
PPO-GRU证明循环记忆本身能够提高随机高度和风扰条件下的投放决策能力，但其缺少MLP前端对当前观测的非线性特征融合，导致在部分复杂状态下更容易出现释放窗口误判。Proposed通过MLP提取瞬时状态特征，再由GRU整合历史动态信息，因此在P90误差和Overall@3m上均优于PPO-GRU，说明MLP-GRU结构能够更有效降低极端落点偏差。
```

## 9. 如何解释 MPC 的低投放率

MPC 的姿态尾部最优，但不能因此说 MPC 整体最好。

建议写：

```text
MPC在成功投放样本中姿态最稳定、冲击最小，这是因为其释放条件较保守，更倾向于等待满足姿态和误差约束的释放窗口。然而在复杂风扰和随机高度条件下，可行释放窗口可能较短或难以满足，导致大量case未完成投放。因此，MPC的dropped-only指标需要与Drop Rate和Overall@3m共同分析。
```

## 10. 最终论文结论建议

加入极端事件分析后，论文结论建议写成：

```text
综合平均性能和极端事件指标可以看出，Proposed在多数复杂工况下取得最低平均误差、最低或较低P90误差以及最高Overall@3m，说明MLP-GRU结构能够有效改善投放时机判断并降低落点误差长尾。PPO在随机高度和多风速条件下出现明显长尾偏差，PPO-GRU虽通过时序记忆改善了该问题，但尾部误差仍高于Proposed。MPC在释放姿态和冲击尾部方面最优，但其投放率较低，导致整体任务成功率不足。因此，本文方法的优势主要体现在复杂扰动下的投放精度、尾部风险控制和整体任务完成能力，而姿态极端风险仍是后续优化方向。
```

## 11. 建议不要加入的说法

以下说法不建议写：

```text
Proposed在所有指标上均优于对比方法。
```

原因：MPC 的姿态和冲击指标明显更好。

```text
Proposed显著提高姿态稳定性。
```

原因：Proposed 的姿态均值和尾部并不优于 MPC，也不总是优于 PPO。

```text
强风条件下仍保持稳定姿态。
```

原因：高风速下 Proposed 和 PPO-GRU 的姿态尾部明显变大。

```text
MPC精度差。
```

原因：MPC 的 dropped-only R@3m 并不总是差，真正问题是投放率低、Overall@3m低。

## 12. 最推荐加入的最小改动版本

如果你不想大改论文，最小加入方案是：

1. 在实验结果开头新增“评价指标与极端事件定义”
2. 在综合结果后增加两张表：
   - 综合投放精度尾部风险表
   - 综合释放姿态极端事件表
3. 在每个实验分析段后加2句话解释 P90 和姿态风险
4. 在结论中增加一句“姿态极端风险仍是后续优化方向”

最小版本需要新增的两个表就是：

- 表A：综合投放精度尾部风险
- 表B：综合释放姿态极端事件风险

这样可以直接回应导师关于“缺少极端事件分析”的意见，同时不会大幅改变论文结构。
